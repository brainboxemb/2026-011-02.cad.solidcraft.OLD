# Documentation

This directory contains repository-level project and migration documentation.

Start here:

- `handoff.md` — compact current repository handoff and next action.
- `plan.md` — source of truth for unfinished work only.
- `requirements.md` — durable repository requirements.
- `design.md` — durable implementation/design decisions.
- `changes/` — numbered historical change records.

Supporting documents such as site baselines or result/provenance notes may live
beside these core files when they are still active. Do not put historical
implementation progress back into `plan.md`; record it under `changes/` or
the relevant GitHub issue.
